# DiscordKit 0.14.0 candidate certification

Verified **2026-10-18**, from clean Phase 13 commit `73a57c7`. This checkpoint
implements Phase 14's documentation, release certification and maintenance tooling.
It is an **unpublished release candidate**, without a package tag or deployment.
REST/Gateway remain **v10**, Voice **v8**, RPC **v1**, MLS **1.0/ciphersuite 2**
and DAVE **v1**. Source verification dates belong to individual affected records.

The [machine report](phase14-report.json) binds passed evidence and explicit
unverified exclusions; [validation](validation.json) gives commands, counts,
source fingerprints and environment limits. [Maintenance](maintenance.json) pins
the reviewed sources and the next review deadline, **2026-10-25**.

## Delivered scope

DocC provides nine independent adoption guides plus lifecycle/freshness/migration
guidance. The commands/components consumer is an offline MainActor composition.
All nine separate consumers build with strict direct-import checks. The actual
manifest/import DAG audit covers 28 products and targets, seven resolved Apple
packages and all nine consumer selections. It exposed and fixed HTTP's missing
direct Core declaration; Core was already linked transitively. No runtime behavior,
root external pin, product boundary or public signature changed.

The owned SwiftSyntax 604.0.0 tool audits private/public/protocol/test/nested
functions, operators, initializers, deinitializers, subscripts and accessors.
All **7,255 explicit callables in 665 Swift files** have comments after fixing
16 missing accessor/getter comments. This is presence evidence. Manual review
covered new/touched declarations and adoption documentation; exhaustive semantic
review of every pre-existing declaration remains unverified and excluded.

The initial API baseline records **13,235 public/open symbols in 28 modules** on
arm64 macOS 13 deployment scope. A fresh snapshot compares identically. Regression
tests enforce version increments for removals, signature/constraint changes,
required protocol members, enum cases and additive changes. There is no earlier
public baseline to establish historical compatibility, binary ABI or other-platform
conditional API compatibility. Local API versions remain distinct from upstream
announcement/effective dates.

Append-only history protects all 24 prior entries. Dated synthetic HTTP channel
fixtures cover **2026-11-15**, the **2026-11-16** effective boundary, empty results
and restored access. Exact IDs above 2^53 and UInt64.max survive decoding.
The decoder follows the response without local date filtering; HTTP omission
cannot distinguish deletion from visibility loss. Gateway obfuscation remains a
separate opt-in. See the [dated parity change](../Parity/changes/2026-10-18-phase14-certification.md).

- Root debug/optimized builds and **2,108 strict root tests in 264 suites across
  29 test targets**, including a complete run with code coverage, pass.
- Tooling, Python, browser, Social catalog, inventory, byte-identical generation,
  parity, dependency/API/documentation audits and independent examples pass;
  exact final totals are in the validation record.
- All **28 public module DocC archives** convert with warnings as errors and
  diagnostic/coverage analysis. Public DocC coverage is not private documentation
  coverage or semantic certification.
- **45 selected Apple module emissions** pass across nine device/simulator SDK
  destinations at package deployment minima. This is selected-module compilation,
  not complete-package cross-builds, linked apps or device/simulator runtime.
- **24 finite local profiles** cover transport/HTTP/Gateway/cache, three arithmetic
  populations and normal/burst load. The named-hardware reports include latency,
  CPU/RSS, request reduction, saturation/recovery and final ownership counters.
  The 30-minute fixed-working-set run completed **201,291 rounds in 1,800.007
  seconds**, with all owned cache/refresh/waiter/subscription/event counters zero
  after shutdown. It admitted 6,441,312 refresh reads through 805,164 loaders
  and explicitly refused 45,089,184 excess offers.

## Measurements and limitations

[Finite run metadata](Measurements/environment.json) identifies the Apple hardware,
executable hash and individual reports. Profiles simulate logical populations;
they do not allocate corresponding users, credentials, sockets or live shards.
Build/test activity overlapped measurements, so these are not controlled
matching-hardware regression comparisons. No three-run baseline regression,
fleet capacity or production performance claim follows. Normal loopback transport
p99 ranges from about **1.47 to 4.25 ms**. Burst saturation/refusals are separate;
the largest burst's p99 is about **25.85 ms** and is not a normal-load SLO result.

The [fresh 30-minute soak](Measurements/soak-accounts-1000000-1800s-burst.json)
retained at most 64 entries, 72,512 accounted bytes, one refresh, eight waiters
and two broadcast events across four scopes and 20 repeatedly used keys per scope.
Actual RSS peaked at 9,797,632 bytes; final RSS was 9,781,248 bytes. RSS increased
16,384 bytes within the final five minutes. All accounted ownership returned to
zero, but this does **not** establish zero resident growth or absence of leaks.
Zero-resource-growth qualification and controlled performance regression review
remain unverified and excluded. Normal transport throughput was approximately
14,919–18,225 successful local exchanges per second, with bounded 8/16/32 socket
cohorts; these measurements do not establish live Discord or fleet capacity.

Sandbox-only loopback/compiler failures were rerun successfully with approved
host-local access. A tool fixture compile encountered duplicate cached Foundation
modules through `/tmp` and `/private/tmp` aliases; fresh canonical compiler caches
resolved it. Environment failures are retained in the validation record.

Unimplemented native adapters, hardware, approved hosts, independent crypto review,
complete interoperability, semantic documentation review, production/fleet and
entire-platform parity remain excluded. This bounded release certification meets
Phase 14's explicit-unverified/excluded rule without closing those gates.
