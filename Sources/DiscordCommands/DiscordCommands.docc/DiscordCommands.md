# ``DiscordCommands``

Define commands, route authenticated interactions and synchronize managed registrations explicitly.

## Overview

DiscordCommands provides macro-free definitions and option builders, exact command/component/modal route keys and bounded registration reconciliation. It depends on signed interaction ownership and the typed REST catalog without requiring Gateway. Constructing a definition, router or reconciler performs no registration or I/O.

Use <doc:DefiningAndRoutingCommands> for invocation behavior and <doc:SynchronizingCommands> for explicit deployment-time registration.
