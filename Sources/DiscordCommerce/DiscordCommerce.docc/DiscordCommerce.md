# ``DiscordCommerce``

Authorize premium features from authoritative entitlements and coordinate explicit consumption or Activity purchase checks.

## Overview

DiscordCommerce is a backend authorization layer over typed entitlement REST operations. It validates exact application, offering, owner, time and consumption policy, while the host owns authenticated sessions, trusted clocks, durable receipt delivery and transport. Construction starts no purchase UI, polling, network work or item grants.

Read <doc:AuthoritativeEntitlements> before authorizing a feature and <doc:PurchasesAndConsumables> before integrating purchases or delivery. Client receipts and subscription snapshots are hints to verify, not authorization.
