# ``DiscordKit``

Build explicitly owned Discord applications from independently adopted Swift products.

DiscordKit targets Swift 6.4 and REST/Gateway v10. Constructors start no tasks or
I/O. Choose a product, supply its authorities and transport, then explicitly own
start and awaited shutdown. The guides pair with separate compile-tested consumer
packages; ordinary verification never supplies Discord credentials.
