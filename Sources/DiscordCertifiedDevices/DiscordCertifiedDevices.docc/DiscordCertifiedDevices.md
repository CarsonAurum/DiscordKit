# ``DiscordCertifiedDevices``

Publish validated, priority-ordered native device descriptions to a local desktop host.

## Overview

Construct immutable metadata from identifiers actually supplied by the host, then publish a complete replacement through an explicit RPC or loopback HTTP path. Publication neither enumerates hardware nor grants Discord certification. The selected desktop host and application approval are independent prerequisites; no background device watcher is installed.

Begin with the guides for ownership and composition, then use the complete type index to explore each declaration and its members. Examples name the additional products they import so you can keep your package dependency graph explicit.
